最重要みずほFG、自律型AIエージェント基盤『Mizuho Cowork』のPoCを発表——Claude Agent SDK×AWS、社員ごとの専用環境（10/5）
みずほFGは10/5、AWSの支援を受け、AnthropicのClaude Agent SDKを活用した自律型AIエージェント基盤『Mizuho Cowork』を開発し、業務適用に向けたPoCを開始すると発表。社員ごとに専用のクラウド作業環境をAWS上に用意し、社員が目標と資料を与えると、エージェントが権限の範囲内で計画・実行する（複数資料の調査・分析、資料作成、画面操作など）。汎用エージェント1種に、業務手順・判断基準・社内ルールを記した『Skills』を部門ごとに追加して多様な業務に対応する設計。
統制面では、汎用エージェント層とみずほ独自層の二層ハーネスで社内ルール準拠のガードレールを実装し、利用者ごとに実行環境・作業領域を隔離（Amazon ECS on AWS Fargate、Amazon S3 Files）、Amazon Bedrock Guardrailsで入出力を制御、ログ・監視を内蔵。必要時は人に確認・承認を求める。PoC対象は案件資料の分析・整理、資料作成、調査データ分析、業務監査のチェック、専門レポートの海外向け要約・翻訳。API非対応の既存システムはブラウザ画面操作で連携する方針。
日経クロステック報道として、2027年度にみずほFG・みずほ銀行・みずほ信託銀行の計約3万人への導入を目指すとの二次情報あり（発表資料に人数記載なし・未確認）。Anthropic社のCowork製品の導入ではなく、同SDKを用いた自社開発である点に留意。
自社示唆：WM固有の発表ではないが、“汎用エージェント＋業務Skills＋共通ガードレール”は、WM部門のRM支援（面談準備・提案書・報告書作成）に転用しやすい構造。自社でも業務手順・判断基準を『Skills』として資産化し、統制（隔離・ログ・承認）を共通基盤側に持たせる方針を検討する。

4. 深掘り特集：データ連携の“値付け”が始まった——AI時代のコントロール・ポイントは料金化されるか

本特集は、Orionの『Connected Ecosystem Support Fee』（10/8報道）を手がかりに、AIエージェントの普及でデータ連携の価値が上がる中、データを握る事業者がアクセスを有料化する動きと、自社のデータ戦略（開放・防御・課金）への含意を整理する。事実はWealthManagement.com報道に基づき、推測は明示する。

1. 何が起きたか（確認できた事実）

WealthManagement.com（10/8）によると、Orion Advisor Solutionsは連携ベンダー各社に、月額の『Connected Ecosystem Support Fee』を導入。同社は“AI・データ基盤のセキュリティ・信頼性・拡張性への継続投資を支えるため”と説明する。ベンダーに届いた通知では定額で約$2,000〜$20,000／月（同誌が確認した範囲）、金額は各社のデータ利用量を反映するとされるが、算定式・データ量は非開示。初回請求は10月下旬、支払期限は11月。2027年1Qには“支援料＋利用量連動”へ移行し、年末までに各社へ利用状況の洞察を提供する計画。OrionはAUA $6.6兆・技術口座860万を抱え、ロードマップとしてパートナー向けのアクセス拡大やMCPアクセスを挙げる。

2. 業界の反応——“新しい常識”か“囲い込み”か

ベンダーの受け止めは割れた。Dispatch社COOは“AI時代のインフラコストとして理解でき、事前に警告を受けていた”と述べた一方、事前通知がなかった、算定根拠が説明されないといった不満も出た。ARQA社のHaik Sahakyan氏は“連携レイヤーは戦略インフラ化しており、課金は透明で利用に比例すべき。名目上オープンでも、独立系開発者が経済的に参加しにくいエコシステムになり得る”と指摘。Singularity Financial Partners社のMichael Roth氏は“AIが接続経由のトラフィックを増やしセキュリティ要件も高めている。小規模ベンダーは連携を止める可能性があり、RIAは誰が費用を負担するか確認すべき”と助言した。Orion側（Reed Colley社長）は、プラットフォームの利用が拡大しており拡張可能なインフラに投資していると説明している。

3. 位置づけ——背景情報と合わせた構図（一部は推測）
